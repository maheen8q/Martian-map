# SHARAD Coverage Analysis — Jezero Crater

## Data source
NASA Planetary Data System (PDS), MRO SHARAD Radargram V2.0.

Instrument: Shallow Radar (SHARAD), Mars Reconnaissance Orbiter.

## Reference location
Jezero study reference point: 77.4°E, 18.4°N.

## Best candidate
S_04138501 is the closest candidate observation.

Its radargram contains 3,600 lines and 3,833 samples per line, with 32-bit floating-point backscatter power.

## Interpretation limitation
These results establish nearby SHARAD radar-track coverage. They do not independently confirm subsurface water ice. Radargram interpretation is required before making ice-detection claims.

## Coordinate method
Distances were calculated from the geometry table's footprint latitude and longitude records using a spherical Mars distance calculation with radius 3,396,190 metres.
